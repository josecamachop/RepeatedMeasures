# ASCA Tutorial

This repository contains the code for reproducing the results of the paper Camacho. ANOVA Simultaneous Component Analysis for Multivariate Repeated Measures Studies. Submitted to Chemometrics and Intelligent Laboratory Systems.

This repository requires the MEDA toolbox v1.13 at https://github.com/codaslab/MEDA-Toolbox

Contact person: José Camacho (josecamacho@ugr.es)

Last modification of this document: 29/May/26



## Organization

The folder contains:

* The script named analysisTN\_ASCA.m performs the real example of the paper.
* The excel file contains the input data.
* The script named runAll performs the simulated results. All the other ".m" files are part of the simulation.
* Figures/ contains the figures generated by the examples.
* html/ contains the publication of results with the Matlab command 'publish'.



## How to use

Install the MEDA Toolbox v1.11 and this repository, and execute "analysisTN\_ASCA".
